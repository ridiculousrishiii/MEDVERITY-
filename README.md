# MEDVERITY

AI-powered evidence verification, nutrition and health intelligence platform.

## Features

- Medical myth verification
- Evidence retrieval
- Nutrition analysis
- Food/product analysis
- OCR product scanning
- BMI calculator
- User authentication
- Search history

## Architecture

Frontend:
React + TypeScript

Backend:
FastAPI + Python

Database:
Supabase PostgreSQL

AI:
LLM + NLP pipeline
